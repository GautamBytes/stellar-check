# Preflight brand and visual direction

The user requested a meaningful new name and a more striking, cohesive website. Working name: Preflight, describing the payment-readiness assessment before signing. Local package name stellar-preflight, version 0.2.0. The existing workspace path and historical proposal documents remain as records.

Direction: architectural glass, pearl surfaces, violet accents and charcoal typography. Centered oversized hero heading leads into original generated glass verification gates with a functional sample report layered on top. The artwork represents a payment passing through checks. It contains no simulated text or controls; all report text and interactions remain HTML.

Colors: pearl #f8f7fb, charcoal #242331, violet #7566da, soft lavender #efecf8, neutral text #727080, success #43836e. Manrope for display/body, IBM Plex Mono for structured values. The working checker receives stronger hierarchy, larger text, nuanced surface contrast, and clear diagnostic states. Feature illustrations, code section, FAQ and footer share the new identity.

Motion: short entry reveal, subtle fine-pointer artwork parallax, hover feedback. Respect reduced-motion settings; never delay access to the checker. Preserve all readiness calculations, fixture/live modes, stale-input handling, keyboard tabs and copy actions.

Verification: typecheck, 92 existing tests, both builds, browser navigation, hero sample cases, checker scenarios, JSON/copy, mobile viewport and full-page visual inspection. No publication or external brand-availability claim is part of this task.

Hero asset: demo/public/preflight-gates.png, generated with the built-in image tool. Prompt: three translucent lilac optical-glass verification gates crossed by a thin luminous path, pearl architectural studio setting, iridescent platinum edges and diffuse shadows, no text/logos/UI. The original generated image is retained in the Codex generated-images directory.
