# Stellar Check

A read-only TypeScript library that checks Stellar payments before signing. Get clear diagnostics for balances, reserves, trustlines, receiving capacity and memo requirements. It never signs or submits transactions.

```sh
npm install stellar-check
```

Using the Stellar SDK directly in your application?

```sh
npm install stellar-check @stellar/stellar-sdk
```

[Visit the website](https://stellar-check-gamma.vercel.app) for the Playground, integration examples, supported checks and limitations.

Node 22.12+ or a modern browser bundler. Apache-2.0 licensed.
