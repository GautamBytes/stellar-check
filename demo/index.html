payment.ts 
import { Networks } from '@stellar/stellar-sdk';
import { checkPayment, HorizonProvider }
  from 'stellar-check';

// Check before asking for a signature.
const report = await checkPayment({
  networkPassphrase: Networks.TESTNET,
  source: senderPublicAddress,
  destination: recipientPublicAddress,
  asset: { type: 'native' },
  amount: '2.5000000',
  feeBudget: '0.0000100',
}, new HorizonProvider(
  'https://horizon-testnet.stellar.org'
));

console.log(report.status, report.coverage);

for (const issue of report.issues) {
  console.log(issue.message, issue.action);
}

CLEAR ANSWERS

Good questions.
Honest answers.

Useful checks start with honest limits.

Does this send or sign a payment?

No. Stellar Check reads public account information and returns a report. Wallet connection, signing and submission remain with your application.

Does “no known issues” guarantee success?

No. The report describes supported checks against separate observations. Account state can change immediately. Recheck before confirmation; signatures, sequence handling and transaction inclusion are outside this tool’s scope.

Which payments can I check?

One ordinary Stellar payment between distinct G addresses, using native XLM or an issued asset. Fee bumps, batches, path payments, Soroban, M addresses, self-payments and payments involving an asset issuer as a party are not supported in this release.

What does the memo check verify?

The official Stellar SDK checks for a declared memo requirement. A supplied memo satisfies a presence check only. Obtain the correct memo from the receiving service; this tool cannot verify the intended customer’s identity.
